# Gorilla Jira 部署与使用说明

## 安装包

当前安装包位置：

```text
D:\gorilla_jira\release\Gorilla Jira Setup 1.0.17.exe
```

未安装版可执行文件位置：

```text
D:\gorilla_jira\release\win-unpacked\Gorilla Jira.exe
```

## 主机作为服务器

1. 在你的电脑安装并打开 Gorilla Jira。
2. 默认会在本机启动服务端口 `37371`。
3. 进入“设置与更新”，查看本机局域网 IP。
4. 如果其他同事无法连接，请在 Windows 防火墙中放行 TCP 端口 `37371`。

连接地址示例：

```text
http://你的局域网IP:37371
```

## 组员连接

1. 组员安装同一个 setup 文件。
2. 打开 App。
3. 在登录 / 注册页的“服务器地址”填入主机地址。
4. 注册账号并进入任务大厅。

## 数据位置

数据默认保存在当前 Windows 用户数据目录中，可在 App 的“设置与更新”中打开。

主要数据包括：

- `gorilla-jira.db`：任务、用户、版本数据。
- `avatars/`：用户头像。
- `attachments/`：任务图片和视频附件。
- `downloads/`：更新包和更新描述文件。

## 桌面浮窗

设置界面可以控制：

- 是否启用浮窗。
- 浮窗是否显示在所有窗口最前面。

浮窗显示当前登录用户、头像和“我的未完成任务”数量，点击浮窗会打开主窗口。

## 桌面版本更新

应用会优先检查 GitHub Releases：

```text
https://github.com/HanStrive/jira/releases/latest
```

发布新版流程：

1. 修改功能后提升 `package.json` 版本号，例如 `1.0.17`。
2. 执行 `npm run dist` 生成安装包。
3. 在 GitHub 仓库创建 Release，tag 建议使用 `v1.0.17`。
4. 上传 `release/Gorilla Jira Setup 1.0.17.exe` 到该 Release 的 Assets。

客户端进入设置页会自动检查最新 Release；如果 GitHub 上的版本号高于本地版本，“软件版本”卡片会显示红点，点击后会打开新版安装包下载地址。如果只推了 tag 但还没有创建 Release 安装包，客户端也会显示红点，但点击后会打开 Releases 页面并提示需要上传安装包。

如果 GitHub 不可访问，仍可在服务器机器的数据目录 `downloads/` 下放置 `app-update.json` 作为局域网兜底更新源。
